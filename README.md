# Urdu ⇄ English Translator

A simple Streamlit web app that translates text between Urdu and English using Google Translate.

## Features
- English → Urdu and Urdu → English
- Proper right-to-left display with Nastaliq font for Urdu
- Copy-friendly output

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Deployed on Streamlit Community Cloud: connect this repo at share.streamlit.io and set `app.py` as the main file.

## Tech
